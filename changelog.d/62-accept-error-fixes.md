Fixed patch
- **Emulator error responses match the real APIs where accept scenarios caught divergences.** BigQuery dataset responses now include the `datasetReference` wrapper, so the Python SDK no longer raises `KeyError` after `create_dataset`. Publishing to a missing Pub/Sub topic names the topic in the NOT_FOUND message. Storage missing-object 404s now carry the GCS-style `errors` array with `reason: "notFound"` and an `X-Goog-Gcs-Base-Ts` header. Resumable uploads with an unknown total size finalise when the client sends the empty `bytes */N` request, instead of looping until the SDK raises `ValueError: Stream is already exhausted.`
